# Panduan Pengawas — KITAQ ONLINE

1. Login di `/admin/login`, buka **Monitoring** sesi Anda.
2. Tampilkan **Layar Proyektor** (alamat situs + token besar + hitung mundur) atau bacakan token. Token berganti tiap 15 menit; siswa yang sudah mulai tidak perlu token lagi.
3. Pantau warna kartu: abu-abu (belum masuk), hijau (mengerjakan), kuning (peringatan), merah (terkunci), gelap (terputus), biru (selesai).
4. Saat alarm berbunyi: lihat feed pelanggaran (jenis: pindah aplikasi, split screen, terjemahan, ekstensi AI, dua perangkat, keyboard fisik).
5. **Buka kunci** hanya setelah memeriksa HP siswa (tutup aplikasi lain, matikan ekstensi/terjemahan). Alasan wajib diisi dan tercatat.
6. Siswa ganti HP (baterai habis, rusak): klik **Reset Login**, siswa login di HP baru dengan token.
7. Sinyal siswa putus: kartu menjadi "terputus", ujian tidak terkunci. Minta siswa tetap mengerjakan; jawaban akan terkirim saat online.
8. Akhir sesi: cetak **Berita Acara** dari menu laporan.
